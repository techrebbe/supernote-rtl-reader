## Bounded trials — record each result before the next

**A. One portrait Edit.** Start stock on page 1, open RTL in portrait, jump to
page 3 and wait for the display to settle. Choose `Edit p.3` once. Expected/PASS:
stock actually finishes opening the same disposable PDF on page 3, without a
loop or duplicate handoff. FAIL: wrong document/page or no successful restart.
Do not draw during this trial. Record marker, requested/actual page, and outcome.

**B. One native stroke, save and RTL return.** On stock page 3 draw one distinct
short stroke inside a labelled box. Turn away/back and gracefully leave/reopen
the stock document to check persistence; observe the stroke's position/size in
the untouched reader. Open RTL and confirm focused page 3, Edit page 3 once, and
inspect stock again. Finally reopen RTL and confirm focused page 3 again.
PASS: that saved stroke survives the existing restart at its original position
and size, and RTL return resumes the correct source location. Capture native
before/after evidence and `.mark` changes, but hashes alone are not proof.
Absence of stock `.mark` ink from the RTL rendering is recorded separately as
NOT_RENDERED (the expected current limitation), not treated as persisted ink loss.

**C. Each landscape half.** Reopen RTL; jump to page 4 and rotate to landscape.
With Cover On, confirm the spread is page 5 left | page 4 right. Edit the right
page once, reopen RTL, then Edit the left page once. PASS for each: stock opens
the exact labelled page (4, then 5). Return to RTL after each and confirm that
its focused source location is correct. No new writing is required here.

**D. Stock page wins on return (two fresh Edit records).** For each subtrial,
enter stock using Edit on the current labelled page, then navigate stock to page
1. Open RTL afresh and record native anchor page 1. First: jump to page 3, Edit
page 3, confirm stock page 3, navigate stock to page 4, then reopen RTL. PASS:
focused source page 4. Second: again establish stock page 1 and a fresh RTL
activation with anchor page 1; jump to page 5, Edit page 5 and confirm stock page
5. Navigate stock back to page 1, rotate once, then reopen RTL. PASS: focused
source page 1, not saved Edit page 5. Each Edit must occur before stock navigation
so its return record is pending, not already consumed. Confirm no duplicate
handoff or wrong-document access; record the first result before the second.

UNKNOWN is required if a result cannot be observed or attributed to this exact
candidate. Do not count UNKNOWN as PASS or add ad-hoc mutations to explain it.

  crash or lost/misplaced disposable ink. Record FAIL; these are acceptable
  research outcomes, not reasons to expose personal data or expand the trial.
  Preserve evidence; only approved, safe cleanup/rollback may follow. Diagnose
  the failed premise before proposing a later device session.

  unintended non-disposable changes, or uncertain save/cleanup state. No further
  installs, pen input or restarts while state is uncertain.
- Use only the previously approved and verified restoration route; preserve
  failed disposable files/logs before cleanup. No firmware/bootloader/system
  changes, forced config replacement, unapproved uninstall, or automatic deletion.
- End by recording the installed package/configuration and whether restoration
  was performed or deferred, confirming a usable stock reader and releasing the
  reservation. Report any uncertainty explicitly; do not claim clean rollback
  without verification.
